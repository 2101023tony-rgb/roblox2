ROBLOX CLUB — 실제 운영용 패키지
===================================

포함 파일
- index.html       웹앱 화면
- style.css        기존 ROBLOX CLUB의 어두운 커뮤니티 허브 분위기를 반영한 스타일
- app.js           Supabase 로그인/회원, 미션, 포인트, 커뮤니티, 보상, 관리자 기능
- supabase-schema.sql  데이터베이스 및 보안 정책
- SETUP.txt        설치 안내

중요
GitHub Pages는 정적 호스팅이므로 회원 데이터 공유/인증/포인트 원장을 직접 저장할 수 없습니다.
이 패키지는 Supabase를 실제 백엔드로 연결합니다. 서버 DB가 없으면 여러 회원이 공유하는 운영 서비스가 될 수 없습니다.
이 패키지는 "데모/로컬 저장"이 아니라 Supabase 연결을 전제로 한 실제 서비스 코드입니다.
다만 보상 상품을 실제로 공급하거나 Robux/상품권을 지급하는 계약·권한은 포함하지 않습니다.

설치 순서
1) https://supabase.com 에서 프로젝트 생성
2) Supabase > SQL Editor에서 supabase-schema.sql 전체 내용을 붙여넣고 Run
3) Supabase > Authentication > Sign In / Providers > Email에서 Email 로그인 활성화
4) Authentication 설정에서 Confirm email을 OFF로 설정
   - 이 앱은 아이디를 가상 이메일(username@members.robloxclub.invalid)로 변환합니다.
   - 확인 메일을 받을 수 없는 주소이므로 이메일 확인을 켜면 가입이 완료되지 않습니다.
   - 비밀번호 재설정 이메일도 제공되지 않으므로 비밀번호를 안전하게 보관하세요.
5) Supabase > Project Settings > API에서 Project URL과 Publishable key(또는 anon public key) 복사
6) GitHub 저장소의 기존 파일을 새 패키지의 index.html, style.css, app.js로 교체 업로드
   - supabase-schema.sql과 SETUP.txt도 함께 올려도 됩니다.
   - 기존 사이트 파일을 먼저 백업해 두세요.
7) GitHub Pages 주소 접속 → 최초 연결 설정 창에 URL과 Publishable/anon 공개 키 입력
8) 회원가입. 아이디는 영문 소문자/숫자/밑줄 4~20자, 비밀번호 8자 이상, 닉네임 12자 이하
9) 본인 계정을 관리자 계정으로 승격:
   Supabase > SQL Editor에서 아래 쿼리 실행. username을 실제 가입 아이디로 바꿉니다.
   update public.user_roles
   set role='admin'
   where user_id=(select id from auth.users where email='가입아이디@members.robloxclub.invalid');

10) 사이트에서 로그아웃 후 다시 로그인하면 관리자 탭이 나타납니다.

운영 기능
- 회원가입/로그인: 아이디+비밀번호+닉네임
- 회원별 포인트: 서버 DB에 기록
- 미션 인증: 회원이 내용/증빙 링크를 제출
- 관리자 심사: 승인 시 포인트 자동 적립, 반려 가능
- 보상 등록: 관리자가 상품과 필요 포인트를 등록. 기본 비공개
- 보상 교환: 회원 신청 → 관리자 승인 시 포인트 차감
- 커뮤니티 게시판: 회원 글 등록 및 목록 조회

보안/운영 주의
- 브라우저에는 Publishable/anon 키만 넣습니다. service_role/secret key는 절대 넣지 마세요.
- 관리자 권한은 브라우저에서 설정할 수 없습니다. 반드시 Supabase SQL Editor에서 한 번 지정해야 합니다.
- 보상은 공급 권한, 미성년자 관련 약관, 발행사 정책 등을 확인한 뒤 활성화하세요.
- Robux를 외부 사이트에서 현금/포인트와 교환하거나 계정 비밀번호를 요구하는 운영은 하지 마세요.
- 게시판은 현재 회원에게 공개됩니다. 개인정보, 전화번호, 주소, 학교, 계정 정보는 게시하지 않도록 운영하세요.
- 정식 운영 전에는 테스트 회원 2개로 가입/미션 승인/포인트/교환 신청 흐름을 점검하세요.
